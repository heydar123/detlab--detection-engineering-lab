# Sigma export

19 of 32 rules are exported as Sigma. These files are generated by `python -m detlab export-sigma`; do not edit them by hand.

Only the detection logic is exported. Site-specific exclusions stay in `rules/` and are listed under `falsepositives` in each Sigma rule.

The queries in `queries/` were produced with pySigma: Sentinel (KQL) with pySigma 1.5.1 and pysigma-backend-kusto 1.0.1; Splunk with pySigma 2.0.2 and pysigma-backend-splunk 3.0.0. The table shows what each tool did with each rule, including the conversions that failed or were partial. None of the queries has been run against a live Splunk or Sentinel instance, so check the field names and the table before using one.
